# i18n

Este arquivo direciona as normas de internacionalização conforme a
responsabilidade envolvida.

## Bundles e chaves

Antes de analisar, revisar, planejar ou modificar bundles, chaves ou traduções
de mensagens, leia e aplique:

- `AGENTS.i18n.messages.md`

## Resolução de mensagens

Antes de analisar, revisar, planejar ou modificar resolvers de mensagens ou
testes e fixtures que os utilizem, leia e aplique:

- `AGENTS.i18n.message-resolvers.md`

Uma referência normativa a este arquivo ativa os especialistas cujos critérios
acima forem atendidos. Ao passar a trabalhar na outra responsabilidade,
reavalie esses critérios.

## Composição local

- Para aplicar um subconjunto fixo que este roteamento não delimite, o
  `AGENTS.md` local deve citar diretamente os especialistas necessários.
- Para usar este roteamento por atividade, o `AGENTS.md` local deve declarar
  uma referência normativa a este arquivo.
- Este arquivo não deve receber novas regras de i18n diretamente; novas regras devem ser criadas ou movidas para um arquivo especialista.
