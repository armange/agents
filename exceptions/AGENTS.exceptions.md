# Exceções

Este arquivo é o ponto de composição das normas de tratamento de exceções.

Antes de analisar, revisar, planejar ou modificar tratamento de exceções, leia
também:

- `AGENTS.exceptions.internal.md`
- `AGENTS.exceptions.interpretation.md`
- `AGENTS.exceptions.logging.md`
- `AGENTS.exceptions.http-exposure.md`

Uma citação deste arquivo ativa obrigatoriamente todas as normas listadas para
o tratamento de exceções no escopo citado.

## Composição local

- Para aplicar apenas um subconjunto, o `AGENTS.md` local deve citar diretamente os especialistas necessários.
- Para aplicar este conjunto completo, o `AGENTS.md` local deve citar este arquivo.
- Este arquivo não deve receber novas regras diretamente; novas regras devem
  ser criadas ou movidas para um arquivo especialista.
