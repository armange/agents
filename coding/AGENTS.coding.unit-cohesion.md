# Codificação: Coesão de Unidades

- Cada unidade de código, como classe, função, método, módulo, componente ou estrutura equivalente da linguagem, deve tratar de um único assunto coeso.
- As operações e os membros da unidade devem estar relacionados exclusivamente ao assunto que ela representa.
- Quando uma unidade assumir responsabilidade não relacionada ao seu assunto, essa responsabilidade deve ser movida para uma unidade dedicada e especializada, na localização compatível com a arquitetura aplicável.
- A separação não deve criar unidades artificiais: operações pequenas e inseparáveis do mesmo assunto podem permanecer juntas.
