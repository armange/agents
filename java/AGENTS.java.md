# Java

Este arquivo direciona as normas Java conforme o código envolvido no trabalho.

## Codificação compartilhada

Antes de analisar, revisar, planejar ou modificar código Java, leia e aplique:

- `../coding/AGENTS.coding.md`

## Métodos, fluxo e nomes

Antes de analisar, revisar, planejar ou modificar métodos ou construtores Java,
leia e aplique:

- `AGENTS.java.methods.md`

Antes de analisar, revisar, planejar ou modificar condicionais, laços ou
instruções Java, leia e aplique:

- `AGENTS.java.control-flow.md`

Antes de analisar, revisar, planejar ou modificar encadeamentos de chamadas de
métodos Java, leia e aplique:

- `AGENTS.java.method-chaining.md`

Antes de analisar, revisar, planejar ou modificar nomes de classes ou métodos
Java, leia e aplique:

- `AGENTS.java.naming.md`

## Lombok e validação declarativa

Antes de analisar, revisar, planejar ou modificar boilerplate, anotações ou
configuração de Lombok em projeto que já o utilize, leia e aplique:

- `AGENTS.java.lombok.md`

Antes de analisar, revisar, planejar ou modificar contratos de entrada,
constraints ou validação estrutural com Jakarta Bean Validation, leia e
aplique:

- `../validation/AGENTS.validation.bean-validation.md`

Uma referência normativa a este arquivo ativa a codificação compartilhada e
os especialistas cujos critérios acima forem atendidos, inclusive suas
dependências normativas. Ao passar a trabalhar em outra responsabilidade,
reavalie esses critérios.

## Composição local

- Para aplicar um subconjunto fixo que este roteamento não delimite, o
  `AGENTS.md` local deve citar diretamente os especialistas necessários.
- Para usar este roteamento por atividade, o `AGENTS.md` local deve declarar
  uma referência normativa a este arquivo.
- Este arquivo não deve receber novas regras Java diretamente; novas regras devem ser criadas ou movidas para um arquivo especialista.
